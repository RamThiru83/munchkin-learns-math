# Munchkin Learns Math

Gentle, interactive maths games for little learners (about ages 4-6, played with a grown-up), ordered from easy to tricky across five levels: Seeds, Sprouts, Buds, Blossoms and Fruits.

Each of the 24 games has five rounds that get a little harder each time, and a **Watch** button that plays a narrated animation of the task being done, voice read-aloud (browser text-to-speech), soft sounds, and no scores to lose.

The games are original and inspired by the preschool maths-circle activities described in the book below. This is an independent project, not affiliated with the author or publisher.

The **For grown-ups** page includes a research-based age guide for each level, with 22 checked references (developmental research, NAEYC/NCTM and Common Core).

**Reference:** Zvonkin, A. (2011). *Math from Three to Seven: The Story of a Mathematical Circle for Preschoolers*. Mathematical Circles Library, Vol. 5. Providence, RI: American Mathematical Society, in cooperation with the Mathematical Sciences Research Institute (MSRI). ISBN 978-0-8218-6873-7.

- `index.html` is the whole site in one self-contained file (no sign-in, no tracking, works offline once loaded).
- `source.zip` contains the readable source (plain ES modules, one file per game) and `build.sh`.
